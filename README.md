## About: 
This is a very simple Max 4 Live device that controls Ableton Live's main Crossfader directly. No additional mapping necesssary. What is unique to this device is that it also works with Push 3 Standalone.

## Download:
On main page of the repository click on green **(<>Code)** button and from drop down click **Downlaod Zip**.

<img width="1407" height="907" alt="Screenshot (2)" src="https://github.com/user-attachments/assets/8182f5fb-9659-4497-9af4-562f21b21c2a" />


Unzip the file. You will get two files: **README.md** and **Crossfader 1.0.amxd** (**Crossfader 1.0** if your extentions are hidden). Then drag over to you Ableton Live and place it in **Presets->Audio Effects->Max Audio Effect**. YOu can create one if it is not there.

<img width="710" height="824" alt="Screenshot (3)" src="https://github.com/user-attachments/assets/b4430e3a-9777-4153-9c4c-eb3738daa9cb" />

After this you should be able to drop it on any channel and control the main crossfader.

## Installing on Push 3 Standalone

From **Presets->Audio Effects->Max Audio Effect** drag the file **Crossfader 1.0.amxd** over to Push location on the left. You can also move it **Presets->Audio Effects->Max Adudio Effect**, but the device should work.

<img width="630" height="705" alt="Screenshot (4)" src="https://github.com/user-attachments/assets/c1bd4e31-4cbd-4737-a5bd-737ad35a0da3" />

## Checking if it works:
At least as of now Push 3 Standalone does not allow slecting **A** or **B** selection on the track to use it with the crossfader. The workaround is to create a project in Abletone Live, create the channels, select either **A** or **B**. Save the project. Port it to Push 3 Standalone. Open it in the standalone mode. Load the **Crossfader 1.0.amxd**. Allow some sound playing out of the channels and fade between the channels.
